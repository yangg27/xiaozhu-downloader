# 小助下载器 · 浏览器扩展

把网页里的视频/音频/压缩包交给本机的小助下载器多线程满速下载。

## 安装（Chrome / Edge 通用）

1. 地址栏输入 `chrome://extensions`（Edge 用 `edge://extensions`）回车
2. 打开右上角的 **「开发者模式」** 开关
3. 点左上角的 **「加载已解压的扩展程序」**
4. 在弹出的窗口里选中 **本文件夹**（即 `browser-extension`，点进去能看到 `manifest.json`），点「选择文件夹」
5. 建议点浏览器扩展栏的拼图图标，把「小助下载器 · 媒体嗅探」固定到工具栏

> 装好后无需任何配置：扩展会自动探测本机下载器的端口并握手取令牌。

## 能做什么

| 功能 | 说明 |
|---|---|
| 媒体嗅探 | 浏览网页时自动记录视频/音频/m3u8/压缩包等资源，图标徽标显示数量 |
| 一键下载 | 弹窗里点「下载」，链接直接送进下载器（带 Referer，防盗链） |
| 下载接管 | 浏览器点下载链接时自动转交下载器（可在弹窗底部切换接管范围） |
| 分析页面 | 交给本机下载器抓取页面，列出静态 HTML 里的媒体 |
| 任务与历史 | 弹窗里看「下载中」进度；「已完成」可点「打开」/「目录」 |

## 权限说明

- `webRequest` / `<all_urls>`：读取响应头判断资源类型（只看头部，不读取内容）
- `downloads`：接管浏览器下载
- 其余（`storage` / `tabs` / `contextMenus` / `notifications`）：保存嗅探结果、右键菜单、完成提醒

**隐私**：所有数据只保存在本机浏览器与本地下载器进程内，不向任何服务器上报。

## 目录结构

```
browser-extension/
├─ manifest.json   扩展清单（MV3）
├─ background.js   后台服务：网络监听、与下载器通信
├─ content.js      页面内脚本：DOM 嗅探、悬浮按钮
├─ content.css     页面内样式
├─ popup.html      弹窗界面
├─ popup.js        弹窗逻辑
└─ icon16/48/128.png  图标
```

## 常见问题

**弹窗显示「未检测到下载器」**
先启动小助下载器（托盘图标在即可）。若刚改过端口，点弹窗里的「启动小助下载器」按钮或重开弹窗会自动重新探测。

**点了「打开」没反应**
文件可能已被移动或删除——此时按钮会变灰，改点「目录」查看所在位置。

**接管没生效**
确认弹窗底部「浏览器下载接管」不是「关闭」，然后刷新一下目标页面（扩展需要重建监听）。
